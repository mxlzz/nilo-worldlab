# D2-AMD — extensión autorizada

Usuario autoriza una única prueba adicional AMD, sin servicios pagos, tras dictamen D2. GitHub documentación https://docs.github.com/en/actions/reference/runners/github-hosted-runners confirma runner estándar gratuito para repos públicos, etiquetas Linux x64 sin selección por fabricante. No se comprobó runner autohospedado AMD ni acceso API. Se realiza **una sola asignación** Ubuntu24.04 x64 con filtro AuthenticAMD antes de instalar o ejecutar física. Si no es AMD, guardar CPU y log y detener: no relanzar automáticamente. Mismo script D2, mismos ZIP y hashes, mismos dos perfiles y dos repeticiones, mismos criterios de comparación con Intel archivado, sin nuevos perfiles. Job máximo 5 min, costo pago cero; sin cambios C.2a/C.2b. Si coincide native con sufijo AMD retenido y fixed con Intel, habilitar prerregistro C.2b-R; si no, preservar negativo/inconcluso y elevar decisión. No afirmar causa universal. Autoverificación.
